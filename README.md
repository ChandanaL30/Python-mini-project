# 🐍 Python Mini Projects

Welcome to my **Python Mini Projects** repository!

This repository contains a collection of beginner-friendly Python projects developed while learning and practising Python programming. Each project focuses on implementing basic programming concepts through simple, interactive applications.

## 📌 Projects Included

### 1. 🎯 Guess the Number
A simple number guessing game where the computer generates a random number between 1 and 100. The user has to guess the correct number with hints indicating whether the guess is too high or too low.

**Concepts Used:**
- Random number generation
- While loops
- Conditional statements
- User input

### 2. 📖 Mad Libs Story Generator
An interactive story generator that takes user inputs such as adjectives, nouns, and verbs to create a fun and personalized story.

**Concepts Used:**
- User input
- Variables
- String formatting
- F-strings

### 3. 🔐 Random Password Generator
Generates a random 12-character password using uppercase and lowercase letters, numbers, and special characters.

**Concepts Used:**
- Random module
- String module
- Loops
- String concatenation

### 4. 📝 To-Do List
A simple command-line task manager that allows users to add, view, and delete tasks through a menu-driven interface.

**Features:**
- Add new tasks
- View all tasks
- Delete tasks
- Exit the application

**Concepts Used:**
- Lists
- Loops
- Conditional statements
- Functions of built-in data structures
- Exception handling

### 5. 🎮 Number Guesser
An interactive number guessing game with two difficulty levels: Easy and Hard. The game tracks the number of attempts taken to guess the correct number.

**Features:**
- Easy mode (1–50)
- Hard mode (1–100)
- Hints for incorrect guesses
- Attempt counter

**Concepts Used:**
- Functions
- Random module
- Conditional statements
- While loops
- Variables

## 🛠️ Technologies Used

## 🚀 Getting Started

Follow these steps to run the projects on your local machine.

### Prerequisites

- Python 3.x installed
- A code editor such as VS Code

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/ChandanaL30/Python-mini-project.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Python-mini-project
   ```

3. Run any project using Python:

   ```bash
   python Guess_number.py
   ```

   Replace `Guess_number.py` with the filename of the project you want to execute.
